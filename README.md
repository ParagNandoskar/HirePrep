# HirePrep

AI-powered resume screening platform with candidate and company portals, JWT authentication, AWS S3 file storage, and Python microservices for resume analysis.

## Deployment

Live app: https://hire-prep-woad.vercel.app/

## Tech Stack

- React frontend
- Node.js and Express backend
- MongoDB database
- Python Flask microservices for NLP and audio analysis
- AWS S3 for file storage
- JWT authentication
